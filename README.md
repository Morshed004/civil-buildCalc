Construction Calculator is a fast, accurate, and offline-ready tool for
estimating construction materials in Bangladesh. Whether you're a
contractor, engineer, or building your own home, this app gives you
instant, reliable numbers for cement, sand, aggregate, bricks, and
steel rebar — all in Bangla, with a clean Amazon-inspired interface.

KEY FEATURES

• Concrete Calculator
  Compute wet/dry volume and material quantities (cement bags, sand,
  stone) for 5 standard mix ratios: 1:1.5:3, 1:2:4, 1:3:6, 1:4:8, and
  1:5:10. Change ratio and results update instantly.

• Brickwork Calculator
  Get exact number of bricks, cement bags, and sand for 5" or 10" walls.

• Steel Rebar Calculator
  Enter diameter, length, and quantity — get weight in kg and tons
  using the standard D²/533 formula.

• Bengali UI
  Designed for the local industry — every label in Bangla.

• Beautiful UI
  Clean Amazon-style theme, smooth animations, and readable typography.

• 100% Offline
  No internet needed. No ads. No tracking.

• Type-Safe
  Built with TypeScript + Expo + React Native for a reliable experience.
